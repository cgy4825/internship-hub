# 系统总体架构

> 本文件描述「校招实习信息聚合站」的整体结构、模块职责与技术选型。

## 1. 定位

一个面向在校生的**校园招聘/实习信息聚合 + 一键跳转投递**的轻量站点。

核心价值：**把分散在各公司官网、招聘平台的实习机会集中展示，点击直达官方投递渠道。**

## 2. 设计原则

1. **索引层，不搬运**：只展示岗位标题、公司、城市、类型、摘要、日期与投递链接，不搬运完整职位描述正文。点击一律深链跳转官方渠道 —— 既贴合需求，又降低版权/合规风险。
2. **近零成本运行**：静态托管（Vercel / GitHub Pages）+ 定时采集（GitHub Actions），避免常驻服务器与数据库开销。
3. **可插拔采集源**：每个数据源是独立模块，坏一个不影响其他；采集器可单独运行、可扩展。
4. **数据与展示解耦**：采集器产出标准 JSON，前端读取渲染；新增数据源不改前端。

## 3. 整体架构

```
┌────────────────────────────────────────────────────────────┐
│                       数据采集层                             │
│  collector/  (Python)                                       │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐                 │
│   │牛客网源   │  │大厂官网源 │  │（扩展）… │  → 各源独立可插拔│
│   └──────────┘  └──────────┘  └──────────┘                 │
│        统一：抓取 → 清洗 → 归一化 → 校验 schema              │
│        产出：data/internships.json（结构化）                 │
└──────────────────────────────┬─────────────────────────────┘
                               │
                               ▼
┌────────────────────────────────────────────────────────────┐
│                       展示层（静态站点）                     │
│  web/  (Vite + React + TS + Tailwind)                      │
│   读取 data/internships.json（运行时 fetch 或构建期引入）    │
│   ├── 列表展示（卡片式）                                     │
│   ├── 搜索 / 筛选（公司/城市/类型/发布日期/行业）            │
│   ├── 收藏（localStorage，无需账号）                         │
│   ├── 今日新增标记（对比日期字段）                           │
│   └── 点击深链跳转投递渠道                                   │
└────────────────────────────────────────────────────────────┘
```

## 4. 数据来源（MVP）

| 来源 | 说明 | 优先级 |
|------|------|--------|
| 应届生求职网（`yingjiesheng`） | 51job 旗下，校招/实习信息集中、SSR 结构稳定，当前主力源 | P0 |
| 各公司官方校招网站 (`company_website`) | 字节、腾讯、阿里等；公开接口多为社招，实习需单独适配 | P1 |

已停用：牛客（讨论区噪声大、接口不稳定）、seed（演示数据）。详见 [`collector.md`](collector.md)。

## 5. 模块职责

| 模块 | 目录 | 职责 |
|------|------|------|
| 数据采集器 | `collector/` | 抓取、清洗、归一化、校验、产出 JSON |
| 前端应用 | `web/` | 展示与交互（搜索/筛选/收藏/跳转） |
| 数据产物 | `data/` | 标准化的 `internships.json`，进 git 供静态托管读取 |
| 文档中心 | `docs/` | 全部规范、架构、决策、schema |
