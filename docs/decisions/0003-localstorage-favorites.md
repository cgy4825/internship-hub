# ADR-0003：MVP 阶段收藏使用 localStorage，不建用户系统

- **状态**：已接受
- **日期**：2025-01-01
- **决策者**：项目发起人 + 开发

## 背景

用户希望对感兴趣的岗位收藏/关注。是否一开始就做注册登录、账号系统？

## 决策

MVP 阶段**不建用户系统**，收藏用浏览器本地存储（`localStorage`）实现。

- 收藏记录存在用户自己浏览器里，无需注册。
- 交互体验即时、无网络等待。

## 备选与取舍

- **注册登录 + 云端同步**：需要后端、数据库、鉴权，显著增加成本与复杂度，且对「信息聚合导航站」MVP 阶段收益低。推迟到后续阶段（标注为 roadmap 增强项）。

## 后果

- 优点：上线最快、零后端成本、用户体验流畅。
- 缺点：收藏只存本机，换设备/清浏览器会丢失；无法跨设备同步。
- 后续如需账号系统，可平滑升级（当前数据层已按 `id` 唯一标识岗位，便于关联用户收藏）。
